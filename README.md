Vehicle Service Reminder System

Overview

The Vehicle Service Reminder System is a simple frontend web application that helps users keep track of vehicle service schedules.

Live webpage https://abinayasai05-boop.github.io/Vehicle-service-reminder-/
Features

- Add vehicle owner details
- Enter vehicle number
- Select service dates
- View upcoming service reminders
- Simple and user-friendly interface

Technologies Used

- HTML
- CSS

How to Run

1. Download the project files.
2. Open "index.html" in a web browser.
3. Use the form to view and manage service reminder details.
